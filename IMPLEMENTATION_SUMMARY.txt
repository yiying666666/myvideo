【核心业务逻辑】
1. FrameExtractor.kt 
   - 统一接口，定义三个方案的通用方法
   
2. MediaMetadataRetrieverExtractor.kt (方案1)
   - 原生API，无依赖
   - 支持任意视频格式的关键帧提取
   
3. FFmpegExtractor.kt (方案2)
   - 高性能方案，支持任意位置提取
   - 使用mobile-ffmpeg库
   
4. ExoPlayerExtractor.kt (方案3)
   - 基于ExoPlayer的视频处理
   - 与播放器无缝集成
   
5. FrameExtractorBenchmark.kt
   - 基准测试工具
   - 自动对比三个方案的性能

【UI组件】
6. VideoFrameSelectorView.kt
   - 自定义View，包含预览+缩略图滚动条
   - 仿剪映设计，支持拖动选择
   
7. FrameThumbnailAdapter.kt
   - RecyclerView适配器
   - 显示缩略图网格，支持选中状态
   
8. VideoSelectorActivity.kt
   - 完整的演示Activity
   - Tab切换展示三个方案
   - 自动性能对比

📝 集成示例
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

// 最简单的用法(推荐)
val extractor = MediaMetadataRetrieverExtractor()
val frames = extractor.extractFrames(videoPath)
val cover = frames.first()  // 第一帧作为封面

// 高性能用法
val extractor = FFmpegExtractor(context.cacheDir)
val frames = extractor.extractFrames(videoPath)
val cover = frames[userSelectedPosition]

// UI集成
selectorView.setFrames(frames, "FFmpeg")
selectorView.setOnCoverSelected { bitmap, timeMs ->
    saveCover(bitmap)  // 保存选中的封面
}
